## 2024-05-18 - [Bulk Inserts vs Try/Except]
**Learning:** [When converting sequential Supabase inserts to bulk inserts, be aware that Supabase does not natively ignore partial batch errors without explicit `on_conflict` semantics. If the original code wrapped individual inserts in `try/except` to ignore duplicates or constraint errors, batching them together changes the error handling behavior—a single error will fail the entire batch. Be careful to only batch inserts that did not rely on ignoring individual errors, or ensure that a bulk insert is truly safe.]
**Action:** [Analyze the original error handling of iterative database inserts carefully. Do not bulk-insert records that have individual `try/except` blocks unless you can replicate the exact error-handling behavior using `on_conflict` or similar DB-level mechanisms.]
